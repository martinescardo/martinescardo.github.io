Alpha-Beta Pruning via Monadic Continuations

Haskell programs for the paper by Martin Escardo and Paulo Oliva, arXiv:2611.32320, November 2026. There is also an Agda companion.
There is one program for each section of the paper with code, following the paper's code in the paper's order, and the two appendices are the modules Utils.hs and K.hs, copied verbatim from the paper. Every addition to the paper's code is marked by a comment ADDED.

Each program traces the plays it evaluates on standard error and prints its result on standard output:

  • Section2.hs, exhaustive search via the continuation monad: 36 plays, then 6.
  • Section3.hs, alpha-beta pruning via the reader monad: 18 plays, then 6.
  • Section5.hs, optimal plays: 18 plays, then (6,[1,0,0,0]).
  • Section6.hs, Tic-Tac-Toe: 9335 plays, then (0,[0,4,1,2,6,3,5,7,8]).

For example, runghc Section6.hs runs the last one. The programs use the package transformers, which comes with GHC.
